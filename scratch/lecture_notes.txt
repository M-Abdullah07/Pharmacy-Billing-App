--- Slide ppt/slides/slide33.xml ---
Steps to do System Testing The following steps are important to perform System Testing: Step 1: Create a System Test Plan Step 2: Create Test Cases Step 3: Carefully Build Data used as Input for System Testing Step 3: If applicable create scripts to - Build environment and - to automate Execution of test cases Step 4: Execute the test cases Step 5: Fix the bugs if any and re test the code Step 6: Repeat the test cycle as necessary
